# VF Activity - Activities & Events

## Overview

VF Activity provides comprehensive activity and event management with scheduling, registration, attendance tracking, and resource booking.

## Features

### Activity Management
- Create activities and events
- Recurring event support
- Activity categorization
- Capacity management

### Registration System
- Individual and group registration
- Online registration via portal
- Waiting list management
- Registration deadlines

### Attendance Tracking
- Digital attendance lists
- Check-in/check-out functionality
- Guardian-reported absences
- Attendance statistics

### Resource Booking
- Resource management
- Availability tracking
- Booking conflicts prevention
- Resource scheduling

## Installation

Requires VF Base, VF Member, VF Group, VF Role, VF Communication, and VF Document to be installed first.

## Configuration

1. Set up activity types
2. Configure registration rules
3. Define resources
4. Set up attendance tracking

## Data Models

- `vf.activity` - Activity definition
- `vf.activity.schedule` - Scheduled sessions
- `vf.activity.registration` - Registration tracking
- `vf.activity.attendance` - Attendance records
- `vf.resource` - Resource management

## Key Features

- Complete activity lifecycle
- Online registration
- Waiting list management
- Resource booking
- Attendance analytics
