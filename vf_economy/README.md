# VF Economy - Financial Reports & Exports

## Overview

VF Economy provides treasurer-focused financial reports, member payment views, and secure export-only access for association financial management.

## Features

### Treasurer Reports
- Revenue reports by category
- Payment status reports
- Budget vs actual comparisons
- Age analysis of outstanding fees
- Excel export capability

### Payment Views
- Filterable payment lists
- Member payment history
- Bulk payment reminders
- Payment statistics
- Custom view configurations

### Export Security
- PDF-only exports (no raw data)
- Access control for exports
- Scheduled report generation
- Email distribution
- Export audit trail

## Installation

Requires VF Base, VF Member, VF Group, VF Role, VF Activity, VF Membership Fees, and VF Template to be installed first.

## Configuration

1. Set up report templates
2. Configure export access
3. Define scheduled reports
4. Set up email recipients

## Data Models

- `vf.economy.report` - Financial reports
- `vf.payment.view` - Payment configurations
- `vf.export.access` - Export security

## Key Features

- Treasurer-focused interface
- Secure PDF exports
- Automated reporting
- Payment tracking
- Export access control
